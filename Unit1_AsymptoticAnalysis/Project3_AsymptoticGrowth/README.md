# Asymptotic Growth Comparison

## Description

This project visualizes and explains asymptotic growth rates used to analyze the time complexity of algorithms.

The project focuses on Big-O, Omega, and Theta notations and compares common growth functions.

## Asymptotic Notations

### Big-O - O

Big-O represents an upper asymptotic bound. It describes how fast an algorithm can grow at most for sufficiently large input sizes.

### Omega - Ω

Omega represents a lower asymptotic bound. It describes the minimum growth rate of an algorithm for sufficiently large input sizes.

### Theta - Θ

Theta represents a tight asymptotic bound. It describes the growth rate when both upper and lower bounds match asymptotically.

## Growth Functions

The common growth functions considered are:

O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ)

## Algorithm Examples

| Growth | Example |
|---|---|
| O(1) | Array Element Access |
| O(log n) | Binary Search |
| O(n) | Linear Search |
| O(n log n) | Merge Sort |
| O(n²) | Bubble Sort |

## Algorithm / Procedure

1. Identify the input size n.
2. List the common asymptotic growth functions.
3. Arrange the growth functions from slower to faster growth.
4. Associate suitable algorithms with their typical complexity.
5. Explain Big-O, Omega, and Theta.
6. Represent the relationships using a concept map.
7. Compare the growth rates as input size increases.
